Data Visualization

KeyboardRage includes exploratory views of the multilingual word dataset. They are built from the same word entries and definition embeddings from IBM Granite Embedding 97M Multilingual R2, but they are meant for visual inspection rather than perfect automatic clustering.

3D Galaxy

The 3D Galaxy was rebuilt from the existing Granite vectors with UMAP using cosine distance, 50 neighbors, and min_dist 0.01. This pulls many true semantic neighbors closer together in the 3D view, so the yellow neighbor links are usually shorter and easier to inspect.

Limitation: this is still a 384-dimensional embedding compressed into only three visible coordinates, so some semantic relationships will remain far apart or visually mixed. For precision, the neighbor panel does not trust 3D distance; it queries the original Granite embeddings with FAISS candidates and exact cosine reranking.

2D Atlas

The 2D Atlas view loads the generated atlas_data.parquet file containing each word, language, definition, and 3D coordinates. It is useful for broad dataset browsing, language-colored overview, and quick visual filtering with Atlas' built-in interface.
